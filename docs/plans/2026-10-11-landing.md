# Landing page redesign — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the landing page with the Claude Design version (`docs/design/landing/design.html`,
screenshots in `public/img/landing/`): seven sections — Arhiva, Autori with the century chart,
Statistika with the growth chart, Transkripti, Kako radi, the closing call to action, footer —
in Serbian and English. Branch `feat/landing`, off `main`.

**Architecture:** Static Serbian HTML, so the page reads without JavaScript; one script swaps the
language, the screenshots and the charts. Every number on the page — counts, both charts — is
computed **at build time** by a Vite plugin from `public/data/geo-events.json` through the app's
own episode model (`lib/episodeModel`), so the landing page can never disagree with the map and
needs no manual regeneration step. Fonts are the self-hosted ones (no Google Fonts).

## Tasks

1. **Stats (`src/landing/archiveStats.ts`)**, pure and tested: counts (episodes, chapters, places
   with a chapter); per-century counts by era for episodes (by anchor) and chapters (by year);
   episodes per publication quarter, cumulative.
2. **Vite plugin (`vite/landingStats.ts`)**: a virtual module with the stats for the page script,
   and `%%stat%%` placeholders in `index.html` filled at build and in dev.
3. **Strings (`src/landing/strings.ts`)**: SR/EN from the design with the decisions above; numbers
   interpolated; Serbian plurals through `lib/plural`. Test: both languages have every key.
4. **Markup and styles**: new `index.html`; `landing.css` rewritten on the explorer's tokens.
5. **Script (`src/landing/main.ts`)**: language (hash, then `hcm-lang`, then sr), screenshots per
   language, the century chart with the Epizode/Poglavlja toggle and tooltips, the growth chart,
   mobile menu, current-section highlight.
6. **Removals**: the live hero map (`landing/hero-map.ts`), the old SVG chart generator
   (`scripts/build-century-chart.mjs`, `npm run chart`) and whatever only it used.
7. **Verify**: tests, build, owner screenshots in SR and EN, desktop and phone.
